# 官网设计记录

日期：2026-10-04。

## 任务与范围

这是 Windows 本地应用启动器的产品官网，不是桌面应用界面的重新设计。用户进入官网要辨认 WinSpot、看见应用的组织与搜索方式、了解本地隐私边界，并找到获取入口。

所有实现都在 `website/`，不修改 Tauri 应用、依赖、设置或数据库。

## 方向

推荐完整初稿采用“山间桌面”：一张真实、明亮的山景桌面壁纸铺满首屏，WinSpot 字标位于天空留白处，玻璃应用库居中叠在桌面上。避免左侧口号、右侧界面卡片的惯常骨架。

备选“键盘宣言”用满版字标、原有彩色标志和快捷键键帽建立更强的发布海报感。两种方向的代表性首屏在 `design/`，由 skill 的原生生成器组装为 `style-explorer.html`。这是推荐初稿，不声称已经经过用户选定。

选择“山间桌面”的依据：原生透明材质、真实图标、分类应用库是 WinSpot 的核心产品证据，桌面上的应用库比抽象几何装饰更容易让普通 Windows 用户理解产品。键盘方向更有海报感，但对应用组织能力的展示较弱。

## 品类与标杆

品类：桌面启动器/个人效率工具的产品介绍网站。

参考对象：Raycast、Flow Launcher、PowerToys Run，作为内容与使用习惯的参照，不作为视觉复刻依据。在线参考未取得足够可核对的画面证据，因此不声称做过它们的实际截图视觉分析。

将品类结构转为本项目的决定：

1. 品牌名称在首屏足够大，不能只有导航中的小字。
2. 启动器本身而非假浏览器外壳承担主视觉。
3. 应用图标和搜索结果承担产品信息，不用虚构数字背书。
4. 快捷键属于实际产品内容，用键帽展示；网页不接管 Win 或 Alt+Space。
5. 获取入口保持可发现，同时尊重“当前提供源码”的状态。
6. 隐私表达保留具体数据类别，不笼统承诺从不联网。
7. 跟随 Windows 用户熟悉的输入、分类和浅深色操作。
8. 不模仿其他平台的设备外壳、三色窗口按钮或终端装饰。

## 视觉关系

- 调性：安静、精致、适中密度、轻分量、稍活泼。工具不打断思路，彩色标志和真实图标保留亲和力。
- 生成引擎：原生玻璃材质 × 自己的桌面；不是为每一段添加玻璃卡片。
- 首屏结构：导航 → 天空留白中的品牌与获取动作 → 居中的应用库 → 视图切换 → 下一段产品特点。
- 字体：英文字标使用 Segoe UI Variable Display/Segoe UI；正文使用 Segoe UI Variable Text 和本地中文回退。字号不按 viewport width 缩放。
- 色彩：白与炭黑承担页面；蓝色承担搜索选中；原标志保留粉橙色；隐私段用浅玫瑰色；外观段为中性炭灰。山景的蓝色属于照片，不扩散为整个站点的主题色。
- 图标：动作使用项目已有 Lucide；应用用本地品牌资源，不使用 emoji。
- 形状：官网按钮与工具控件为 3–8px；启动器本体延续原应用较大的圆角。
- 页面段落不加浮动卡片；搜索展示是有明确边界的工具表面。

## 内容与交互

主动作：获取 WinSpot → 获取区 → 项目源码或发布页。不伪造安装包版本、下载成功、客户评价或性能成绩。

展示链：

- 分类筛选、应用选择、输入查询、空结果、清空恢复。
- 应用库/聚焦搜索切换，选中状态和结果计数同步。
- 中文、拼音、首字母展示；输入法组合期间不处理确认启动。
- 键盘选择限定在展示工具中，不劫持网页全局或系统快捷键。
- 外观切换、透明度滑块和壁纸选择，仅改变官网展示。
- FAQ 使用原生 details；移动导航有关闭、Esc 和外部点击恢复。

三处基本动效：品牌与启动器首次到场；视图选中底板移动；按钮按下和结果切换反馈。统一为短促、从控件附近发生的动作。支持 reduced-motion，不加入持续循环、滚动劫持或全页视差。

## 素材

- 标志来自 `src/assets/logo.png`，原文件未修改。
- 两张 Unsplash 照片作为桌面壁纸，不作为真实产品截图。
- 产品界面是 HTML/CSS 重建的可交互展示，数据是固定的演示集合。
- 常规动作从本地 `lucide-solid` 提取；部分文件图标从项目已有 VS Code Icons 提取。
- 其他应用标志来自 Devicon 与 Simple Icons。来源及许可见 `THIRD_PARTY_NOTICES.md`。
- 页面运行时不需要网络下载素材。

## 真实样式实现说明

将官网展示从简单 mock 全面升级为 WinSpot 桌面应用的原生设计系统（对齐 `src/styles.css` 与 `src/Launcher.tsx`）：

1. **毛玻璃与合成材质**：引入真实的 `--glass-*` 与 `--mac-*` 设计变量、`.native-surface`、顶部径向高光反射（`::before`）、细微噪点颗粒纹理（`::after`）及深色模式黑曜石玻璃。
2. **原地极致变形卡片**：
   - **程序库 (Application Library)**：Win 11 悬浮回退按钮、Mac 风格输入框与灰色补全药丸（`match-pill`）、8 个分类胶囊标签栏、7 推荐应用行、细分割线、7 列真实网格、60px 图标柔和阴影、固定应用徽标以及选中图标外围标志性的 2px 强调色圆角细线。
   - **聚焦搜索胶囊 (Spotlight Capsule)**：无输入时收缩为 60px 椭圆胶囊，右侧感应区域悬浮时平滑展开两个独立的毛玻璃圆形按钮（应用库、文件搜索）。
   - **聚焦搜索展开 (Spotlight Expanded)**：输入时平滑向下展开为左右分栏——左侧结果列表、右侧完整 Inspector 详情预览（60px 大图标、分类标签、真实目标路径、操作按钮）与底部快捷键指引栏。
3. **交互与主题**：支持拼音/首字母实时过滤、全键盘方向键导航、Tab 视图切换、Esc 清除及 Sun/Moon 深浅色材质无缝切换。

## 减法与细节

删除或主动不加入：英文装饰眉标、版本徽章、虚构用户统计、重复功能卡片、自动播放动画、假的应用启动成功提示、独立的浏览器设备外壳。

保留：品牌、系统要求、真实来源入口、应用名称、搜索选中和计数、隐私数据种类、安装限制、FAQ。

源码层面已处理：Grid/Flex 子项可收缩、输入框边界、长应用名、窄屏键帽宽度、移动导航、短高度首屏、焦点、外链安全属性、固定媒体比例和 reduced-motion。应用库、搜索及空状态使用共享的高度变量，切换不改变主视觉的总高度；深色展示中的深色标志补充了可辨识处理。

## 验证记录

仅进行静态检查，不启动 dev/build，不使用 Computer Use、Playwright、WebDriver 或其他界面自动化。

- JavaScript 语法检查。
- HTML 解析、ID/锚点和本地资源引用检查。
- CSS 解析和图标资源检查。
- 审阅交互状态、IME guard、清空与空结果、非实际启动边界。
- 确认更改局限于 `website/`。

未进行：浏览器实际渲染、100%/200% 视觉检查、桌面/手机截图、三帧动效取证、独立视觉评审、实际任务走查。原因是项目明确禁止代理执行 UI 自动化验收。没有虚构视觉评分；当前只交付源码层面检查结果。

证据：本目录源码、方向小样、manifest 和离线对比页。没有截图或录屏证据。建议人工关注 1440×900、1366×768、390×844、375×667、320px 窄屏及 200% 缩放。
